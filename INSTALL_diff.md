# 📦 Инструкция по скачиванию и установке

## Что входит в архив

```
garden-assistant/
├── src/                    # Исходный код
│   ├── components/
│   │   └── PlotMap.tsx    # Интерактивная карта участка
│   ├── App.tsx            # Главный компонент
│   ├── LanguageContext.tsx # Контекст локализации
│   ├── i18n.ts            # Переводы RU/EN
│   ├── types.ts           # Типы TypeScript
│   ├── data.ts            # Данные приложения
│   ├── main.tsx           # Точка входа
│   └── index.css          # Стили
├── public/
│   └── _redirects         # Netlify redirects
├── dist/                   # Готовый сайт (после сборки)
├── netlify.toml           # Конфигурация Netlify
├── package.json           # Зависимости
├── tsconfig.json          # TypeScript конфиг
├── vite.config.js         # Vite конфиг
├── README.md              # Основная документация
├── DEPLOY.md              # Инструкции по публикации
└── index.html             # HTML точка входа
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Откройте браузер: `http://localhost:5173`

### 3. Сборка для публикации

```bash
npm run build
```

Готовый сайт будет в папке `dist/`

## 🌐 Публикация на Netlify

### Способ 1: Drag & Drop (самый простой)

1. Выполните `npm run build`
2. Откройте [app.netlify.com/drop](https://app.netlify.com/drop)
3. Перетащите папку `dist/` в окно браузера
4. Готово! Получите ссылку

### Способ 2: Через GitHub

1. Загрузите проект на GitHub
2. Подключите репозиторий к Netlify
3. Netlify автоматически соберёт и опубликует сайт

Подробности см. в [DEPLOY.md](DEPLOY.md)

## 🎯 Основные функции

### Регистрация
- Выбор языка (🇷🇺 / 🇬🇧)
- Ввод имени, email, телефона
- **Адрес участка** с автоопределением климатической зоны
- Выбор аватара

### Профиль
- Просмотр всех данных
- **Редактирование** личных данных
- Изменение адреса (автообновление климатической зоны)
- Смена аватара
- **Выход из аккаунта**
- **Смена аккаунта**

### Участок

- Добавление/удаление строений
- Перемещение строений (drag & drop)

- Добавление растений
- QR-коды

## 💡 Советы

1. **Первый запуск**: выберите язык и зарегистрируйтесь
2. **Адрес участка**: укажите реальный адрес для корректного определения климатической зоны
3. **Профиль**: можно редактировать в любой момент
4. **Участок**: начните с добавления строений, затем растений
5. **QR-коды**: распечатайте и прикрепите к растениям

## 🐛 Возможные проблемы

### Не запускается `npm run dev`
```bash
# Удалите node_modules и package-lock.json
rm -rf node_modules package-lock.json
npm install
```

### Ошибки TypeScript
```bash
# Проверьте версию Node.js (должна быть 18+)
node --version

# Переустановите зависимости
npm install
```

### Не собирается проект
```bash
# Очистите кэш
npm run clean

# Пересоберите
npm run build
```
