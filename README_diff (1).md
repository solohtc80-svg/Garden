# 🌱 Садовод / Garden Assistant

Интеллектуальное веб-приложение для садоводов и огородников с поддержкой русского и английского языков.

![Version](https://img.shields.io/badge/version-2.0.0-green)
![React](https://img.shields.io/badge/React-18.2-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5.7-blue)
![Tailwind](https://img.shields.io/badge/Tailwind-4.1-38bdf8)

## 📋 Описание

Полнофункциональное приложение для управления садовым участком с интерактивным планом, QR-кодированием растений, AI-диагностикой болезней, лунным календарём и многим другим.

## ✨ Основные возможности

### 🗺️ Интерактивный план участка
- **Изменение размера участка** — настройка ширины и длины в метрах
- **Добавление строений** — дом, теплица, сарай, баня, гараж, колодец и др.
- **Удаление строений** — одним кликом
- **Изменение размера строений** — перетаскиванием угла или через числовые поля
- **Перемещение строений** — drag & drop
- **Слои карты** — постройки, дорожки, грядки, коммуникации, рельеф

### 🌱 Управление растениями
- Размещение на плане двойным кликом
- Карточка растения с информацией о виде
- QR-коды с возможностью печати
- Привязка к справочнику видов (Species)

### 📅 Календарь ухода (CareEvent)
- Задачи полива, подкормки, обрезки
- Отметка о выполнении
- Прогресс-бар

### 🌙 Лунный календарь
- 7-дневный прогноз с фазами Луны
- Рекомендации по посадке/обрезке
- Знаки зодиака

### 🤖 AI-диагностика (DiseaseRecord)
- Имитация анализа фото растения
- Определение болезни и степени опасности
- Рекомендации по лечению
- История диагнозов

### 📚 Справочник видов (Species)
- 10 видов растений с характеристиками
- Потребности в воде, свете, типе почвы
- Поиск по названию

### 💬 Сообщество (Message)
- 7 тематических чатов
- Личные сообщения
- Отправка сообщений в реальном времени

### 🌤️ Погода
- Текущая погода с ощущаемой температурой
- Прогноз на 7 дней
- Рекомендации для садоводов

### 🧺 Урожай (Harvest)
- Статистика сборов
- Графики по культурам
- Экспорт данных

### 📝 Дневник садовода
- Записи с настроением и погодой
- Теги и фото

### 🛒 Биржа семян и саженцев
- Обмен и продажа
- Фильтры по типу

### 🧮 Калькулятор удобрений
- Расчёт дозы по площади и типу почвы

### 🏆 Достижения
- Система бейджей
- Прогресс-бар

### 📡 IoT-устройства
- Интеграция с Xiaomi, Gardena, RainMachine
- Статус онлайн/оффлайн

### 🗄️ Схема БД
- Визуализация всех 9 таблиц
- Связи между таблицами (1:N)
- Статистика данных

## 🗃️ Структура базы данных

```
User (1) ──── (N) Garden (1) ──── (N) Plant (1) ──── (N) CareEvent
  │                │                   │                  (N) DiseaseRecord
  │                │                   │                  (N) Harvest
  │                │                   └── (1) Species
  │                └── (N) Building
  └── (N) Message
```

### Таблицы:
| Таблица | Описание |
|---------|----------|
| **User** | Пользователи (id, email, password_hash, name, region, climate_zone) |
| **Garden** | Участки (id, user_id, name, area, width_m, height_m, gps_coords) |
| **Building** | Строения (id, garden_id, name, type, x, y, width, height, color, icon) |
| **Species** | Виды растений (id, name, category, water_needs, light_needs, soil_type) |
| **Plant** | Растения (id, garden_id, species_id, variety, planting_date, position_x/y, qr_code) |
| **CareEvent** | Задачи ухода (id, plant_id, type, scheduled_at, done_at) |
| **DiseaseRecord** | Болезни (id, plant_id, photo_url, diagnosis, treatment, date) |
| **Message** | Сообщения (id, sender_id, receiver_id, chat_id, text, created_at) |
| **Harvest** | Урожай (id, plant_id, date, weight_kg, note) |

## 🚀 Установка и запуск

### Требования
- Node.js 18+
- npm 9+

### Установка

```bash
# Клонировать или распаковать архив
cd garden-assistant

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать production-версию
npm run build
```

## 🎮 Использование

### Регистрация
1. При первом запуске выберите язык (🇷🇺 или 🇬🇧)
2. Заполните форму регистрации или войдите как демо-пользователь
3. Данные сохраняются в localStorage

### Работа с участком
1. Перейдите в раздел **«Участок»**
2. Нажмите **«Размер участка»** для изменения габаритов
3. Нажмите **«Строение»** для добавления нового
4. **Двойной клик** по пустому месту — добавить растение
5. **Клик** по строению — выбрать и перетащить
6. **Угол строения** — потянуть для изменения размера

### QR-коды
1. Выберите растение на плане
2. Нажмите **«QR-код»**
3. Нажмите **«Печать»** для создания наклейки

## 🎮 Использование

### Регистрация
1. При первом запуске выберите язык (🇷🇺 или 🇬🇧)
2. Заполните форму регистрации:
   - Имя, email, пароль, телефон
   - **Адрес участка** (автоопределение климатической зоны)
   - Выбор аватара
3. Данные сохраняются в localStorage

### Редактирование профиля
1. Перейдите в раздел **"Профиль"**
2. Нажмите **"Редактировать"**
3. Измените любые данные:
   - Имя, email, телефон
   - Адрес участка (климатическая зона обновится автоматически)
   - Аватар
4. Нажмите **"Сохранить изменения"**

### Выход и смена аккаунта
- **Выйти из аккаунта** — очистит данные и вернёт на экран входа
- **Сменить аккаунт** — позволит зарегистрироваться под другим пользователем

### Работа с участком
1. Перейдите в раздел **"Участок"**
2. Нажмите **"Размер участка"** для изменения габаритов
3. Нажмите **"Строение"** для добавления нового
4. **Двойной клик** по пустому месту — добавить растение
5. **Клик** по строению — выбрать и перетащить
6. **Угол строения** — потянуть для изменения размера
