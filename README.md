Садовод — интеллектуальное веб-приложение для садоводов и огородников, предлагающее интерактивный план участка, учет растений с QR-кодами, календарь ухода и лунные рекомендации. Ключевые функции включают AI-диагностику болезней по фото, прогноз погоды, дневник урожая и сообщество. 
Приложение поддерживает два языка, автоматически определяет климатическую зону по адресу и разработано на стеке React 18 + TypeScript + Tailwind CSS. Версия 2.0.0 готова к продакшену и развертыванию на Netlify.
